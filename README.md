# odin-recipes
A simple HTML website with few recipes

## Project description
The project consists of a simple HTML-only website with a homepage linked to three recipes.
Each recipe has an image, a description, ingredients and steps to prepare it.
Each recipe also has a link back to the homepage and attribution to the author's image.

## Skills and technologies demonstrated
- Using basic html tags to create basic webpages
- Creating a basic website structure with links (homepage - linked pages)
- Inserting images and attributions to their author
- Basic git/GitHub usage (create repo, clone, add, commit, push)
- Publishing a webpage using pages function in GitHub
